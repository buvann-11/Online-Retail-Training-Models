# Online Retail – Training Models

Hands-On Machine Learning (Géron, 2nd ed.) – **Chapter 4: Training Models**, applied to the UCI Online Retail II dataset (`online_retail_II.csv`).

## Contents
- Linear Regression; MSE, RMSE, R²
- Normal Equation and pseudoinverse with NumPy
- Batch Gradient Descent and Stochastic Gradient Descent from scratch (learning-rate effects, learning schedule)
- SGDRegressor and mini-batch GD with `partial_fit`
- Polynomial Regression and learning curves
- Regularization: Ridge, Lasso, Elastic Net; early stopping
- Logistic Regression (decision boundary, thresholds, log loss)
- Softmax Regression for 3-class revenue bands

## Run
Put `online_retail_II.csv` next to the notebook and run all cells (scikit-learn, pandas, matplotlib).
